# protobuf

Protocol Buffers in Zig: a field-by-field reader and writer for the wire format, with no .proto files, no generated code, and caller-owned buffers.

This project is incubating. It is unstable, its API will change, and it is not ready to depend on.

## Work on it

`nix develop` provides the toolchain, and `just ci` runs what CI runs.
